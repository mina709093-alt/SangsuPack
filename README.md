# 상수팩 (SangsuPack)

와우 포에버(WoW: Forever)용 애드온 묶음입니다. **WowUp**으로 설치하면 업데이트 버튼 한 번으로 최신 버전을 받을 수 있습니다.

## 처음 설치하기

1. [wowup.io](https://wowup.io)에서 WowUp을 받아 설치합니다.
2. WowUp을 실행하고 위쪽 목록에서 **포에버**를 선택합니다.
   목록에 없으면 설정에서 `World of Warcraft\_forever_` 폴더의 실행 파일을 직접 지정해 주세요.
3. **Get Addons** → **Install from URL**을 누릅니다.
4. 아래 표의 주소를 하나씩 붙여 넣고 설치합니다. 원하는 애드온만 골라 설치해도 됩니다.
5. 게임을 켜거나, 이미 켜져 있다면 `/reload`를 입력합니다.

구글 드라이브에서 받아 직접 넣은 상수팩 애드온이 있어도 그대로 설치하면 됩니다. 기존 폴더를 덮어쓰고, 설정은 WTF 폴더에 따로 저장돼 있어서 그대로 남습니다.

## 애드온 목록

| 애드온 | 하는 일 | WowUp 설치 주소 |
|---|---|---|
| ReagentSource (재료 획득처) | 제작 재료 툴팁에 판매 NPC / 드랍 몬스터 위치 표시 | https://github.com/mina709093-alt/ReagentSource |
| KQuestGuide (퀘스트 길잡이) | 받을 퀘스트와 제출할 퀘스트를 가까운 순서로 안내 | https://github.com/mina709093-alt/KQuestGuide |
| DisenchantHelper (마력 추출 도우미) | 마력 추출 가능 아이템 표시, 경매장 필터, 일괄 추출 보조 | https://github.com/mina709093-alt/DisenchantHelper |
| RotaKey (매크로 메이커) | 스킬 순서를 그룹별로 만들고 퀵슬롯 아이콘 하나로 연타 실행 | https://github.com/mina709093-alt/RotaKey |
| BuffAlert (버프 알림) | 등록한 버프가 사라지면 아이콘과 알림음으로 알림 | https://github.com/mina709093-alt/BuffAlert |
| QuestNavigator | 장비 / 특성 / 퀘스트 보상 정보 검증용 | https://github.com/mina709093-alt/QuestNavigator |
| LootAssist (전리품 도우미) — 테스트 중 | 주사위 창에서 입찰 / 양보 / 차비 판단을 도움 (개발 중, 기능이 계속 추가됨) | https://github.com/mina709093-alt/LootAssist |
| SangsusStyle (상수 스타일 UI) | 액션바·유닛 프레임·채팅·미니맵·각종 창을 어두운 평면 "상수 스타일"로 바꾸고, 이동 모드로 위치·크기 조절 | https://github.com/mina709093-alt/SangsusStyle |

## 업데이트하기

WowUp에서 **My Addons** → 새로고침(↻) → **Update** (또는 **Update All**)를 누릅니다.

게임 안에서 "최신 버전이 업데이트 되었습니다"라는 알림이 보이면, 같이 접속한 친구가 더 새 버전을 쓰고 있다는 뜻입니다. WowUp에서 업데이트해 주세요.
`/상수팩`을 입력하면 설치된 애드온과 버전을 볼 수 있습니다.
